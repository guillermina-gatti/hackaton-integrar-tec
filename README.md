# 👻 The Ghost's Claims Office

> *La Oficina de Reclamos del Fantasma*
> *Your complaint is very important to us. Please wait without moving.*

A ghost opened a claims office for living people who don't scare easily. You file your complaint, the office assigns a file number, a priority and a deadline, and gives you an **official receipt** signed by The Ghost. You can file it with your name or anonymously, and you can file it against the person responsible (the neighbour in 3B, the gnome in the library, the witch at the kiosk).

## 🧪 How to run and test it

Requirements: Node.js 24 or later and pnpm.

```bash
git clone <repo-url>
cd hackaton-integrar-tec
pnpm install
pnpm dev
```

`pnpm dev` starts both services in one terminal:

- API on `http://localhost:4000` (Swagger at `/api/docs`)
- Web on `http://localhost:3001`

Steps:

1. Open `http://localhost:3001`.
2. Fill in the form: your name (or tick "anonymous"), optionally who the claim is against, the reason, and a short description.
3. Click **Presentar reclamo →**.
4. You should see the official receipt with the file number, priority and deadline. The new claim appears at the top of the live board. Use **+ 8 aleatorios** to fill the board with test claims.

Claims are kept in memory, so restarting the API clears the board. Claims marked "muestra" are samples generated by the board. If the page says the API is not responding, open `http://localhost:4000/api/reclamos` in your browser. If it doesn't load, the API is not running. You can also run the services separately with `pnpm dev:api` and `pnpm dev:web`.

## 🔌 Endpoints

| Method | Route | Purpose |
|---|---|---|
| `POST` | `/api/reclamos` | Submit a claim and get the receipt |
| `GET` | `/api/reclamos` | List the board's claims, newest first |
| `POST` | `/api/reclamos/aleatorios?cantidad=8` | Generate test claims (maximum 30) |

### Submit a claim

```json
{
  "nombre": "Juan Pérez",
  "anonimo": false,
  "tipo": "sombra robada",
  "reclamadoA": "El Vecino del 3B",
  "descripcion": "Mi sombra se fue al cine sin avisar"
}
```

If `anonimo` is `true`, `nombre` is not required and the claim is shown as "Anónimo". `reclamadoA` is optional.

Response:

```json
{
  "expediente": "FANT-0001",
  "prioridad": 1,
  "plazoDias": 1,
  "comprobante": "File FANT-0001 | Juan Pérez | Priority 1 | Resolution in 1 day | Claimed against: El Vecino del 3B | Signed: The Ghost"
}
```

## 📚 Frequently asked questions

**Will my claim be resolved?**
It has a file number, a priority and a deadline. We do not guarantee that the ghost reads it before getting scared himself.

**Can I file anonymously?**
Yes. Tick the anonymous option and your name does not appear on the board or on the receipt. The office does not ask why.

**Can I complain about the cold in my own house?**
Yes. The office does not check whether the heating is broken or whether the ghost moved to the living room.

**What if my shadow comes back before the deadline?**
The file closes automatically. We keep it on record in case it disappears again.

**Do I have to pay anything?**
Only the embarrassment of leaving your shadow at the cinema.
